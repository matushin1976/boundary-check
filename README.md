# 境界点間精度管理表

A-Surveyから出力した境界点間CSVを読み込み、A4横の精度管理表を表示・PDF保存するブラウザアプリです。

## 使い方
1. `index.html` をブラウザで開く（GitHub Pagesにも対応）。
2. A-SurveyのCSVを選択する。
3. 業務名・測量年月日・作業者を入力する。
4. 「PDF出力」を押し、印刷画面で「PDFに保存」を選択する。

CSV列：点間、計算距離(m)、実測距離(m)、較差(m)、許容値(m)、許容範囲。UTF-8/Shift_JIS対応。元CSVの較差との不一致は※表示。ファイルはブラウザ内で処理し、外部送信しません。

※ PDF生成はブラウザの印刷機能を利用します。正式な成果として使用する前に数値・様式を確認してください。
